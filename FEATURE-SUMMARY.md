# Personal OS Feature Summary

## Goals

Goals support:

- Title and description
- Current and target values
- Custom units
- Target dates
- Active, completed, paused, and archived states
- Progress calculation

Route: `/personal-os/goals.php`

API: `/personal-os/api/goals.php`

## Daily journal

The journal supports:

- One entry per day
- Mood selection
- Energy level
- Gratitude
- Daily wins
- Reflection notes
- Current consecutive-day streak

Route: `/personal-os/journal.php`

API: `/personal-os/api/journal.php`
